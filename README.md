# Gojo JJK Mod

A Minecraft Fabric mod that adds Gojo Satoru's incredible powers from Jujutsu Kaisen to **Minecraft 1.21.11**!

## 📥 Download

**[View Releases & Downloads](https://github.com/lamper90000-png/gojo-jjk-mod/releases)**

To download the latest version:
1. Go to the [Releases page](https://github.com/lamper90000-png/gojo-jjk-mod/releases)
2. Download the `.jar` file (e.g., `gojo-jjk-mod-1.0.0.jar`)
3. Place it in your `.minecraft/mods/` folder

Or **build it yourself** from source (see below)

### Requirements
- Minecraft 1.21.11
- [Fabric Loader 0.18.1+](https://fabricmc.net/)
- [Fabric API 0.140.2+1.21.11](https://www.curseforge.com/minecraft/mc-mods/fabric-api)
- Java 21+

### Installation
1. Download [Fabric Loader](https://fabricmc.net/use/) for 1.21.11
2. Download [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api) for 1.21.11
3. Download this mod JAR from the Releases page
4. Place all mod JARs in your `.minecraft/mods/` folder
5. Launch Minecraft with the Fabric profile

## 🔮 Features (In Development)

- **Limitless Technique**: The foundational cursed technique
- **Infinity**: A defense that creates an impenetrable barrier
- **Blue**: A repulsion-based attack that sends enemies flying
- **Red**: An attraction-based attack that pulls enemies in
- **Purple**: The combination of Blue and Red for devastating damage
- **Domain Expansion**: Unlimited Void - Creates an overwhelming domain

## 🛠️ Building from Source

```bash
git clone https://github.com/lamper90000-png/gojo-jjk-mod.git
cd gojo-jjk-mod
./gradlew build
```

The compiled mod will be in `build/libs/gojo-jjk-mod-1.0.0.jar`

## 📚 Development Setup

```bash
./gradlew genSources
./gradlew ideaModule  # For IntelliJ IDEA
```
