# Gojo JJK Mod

A Minecraft Fabric mod that adds Gojo Satoru's incredible powers from Jujutsu Kaisen to Minecraft 1.21.1!

## Features (In Development)

- **Limitless Technique**: The foundational cursed technique
- **Infinity**: A defense that creates an impenetrable barrier
- **Blue**: A repulsion-based attack that sends enemies flying
- **Red**: An attraction-based attack that pulls enemies in
- **Purple**: The combination of Blue and Red for devastating damage
- **Domain Expansion**: Unlimited Void - Creates an overwhelming domain

## Requirements

- Minecraft 1.21.1
- Fabric Loader
- Fabric API
- Java 21+

## Installation

1. Install [Fabric Loader](https://fabricmc.net/use/)
2. Place the mod JAR in your `mods` folder
3. Launch Minecraft with the Fabric profile

## Building

```bash
./gradlew build
```

The compiled mod will be in `build/libs/`

## Development Setup

```bash
./gradlew genSources
./gradlew ideaModule  # For IntelliJ IDEA
```
